## How DBF Commander Professional Sits

DBF Commander Professional does not replace the spreadsheet you already use for summaries. It sits beside that sheet as named field tools for DBF Commander Professional DBF tables you keep.

The data desk stays small on purpose. Extra dBase files wait for their own title instead of crowding the live DBF Commander Professional data desk.

## Traffic Light

| Signal | On the DBF Commander Professional desk | What you do |
|--------|----------------------------------------|-------------|
| Green | Named DBF table, field tools on your records | Continue the same data desk |
| Amber | Fields from two tables mixed | Split the set before a large change |

| Clear | Handoff written, field list short | Close DBF Commander Professional and leave the file |

## Open Order

1. Open the last DBF Commander Professional session on a DBF you keep, not a new empty table.
2. Read the field tools and the last handoff on that file.
3. Finish one visible field change inside DBF Commander Professional DBF tables.
4. Write what changed on your own records, then close with fewer loose dBase files than you found.
5. If the desk feels crowded, drop anything that belongs to a different DBF job.
6. Leave field tools on the same named DBF Commander Professional data desk.

## After a Week

A week in DBF Commander Professional is not more open tables. It is the same field tools, a shorter field list, and a note that still makes sense on Monday.

Other programs stay where they are. DBF Commander Professional only keeps the path back: table name, fields, records, handoff.

## Sign-off

- [ ] The DBF Commander Professional table name is short enough to scan
- [ ] Only DBF tables you keep are open
- [ ] A second person can read the last field change
- [ ] The last DBF Commander Professional session still opens after a restart
- [ ] Finished field jobs are off the live data desk
- [ ] Field tools still match DBF Commander Professional dBase files
- [ ] The data desk handoff still names the table you own

## Field Note

DBF Commander Professional is easier to trust when the field list stays smaller than the folder of DBF copies around it. Name the table, keep DBF Commander Professional field tools on records you own, finish one visible step, and write what changed.

The same loop fits a shop file, a clerk packet, or a shared computer. Open the last DBF Commander Professional data desk and continue. Do not rebuild the field layout from scratch.
